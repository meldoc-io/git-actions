# Example Action

This is an example GitHub Action demonstrating the structure for actions in this monorepo.

## Usage

```yaml
- uses: meldoc-io/git-actions/actions/example-action@example-action/v1.0.0
  with:
    input1: 'custom-value'
```

## Inputs

| Input | Description | Required | Default |
|-------|-------------|----------|---------|
| `input1` | Example input parameter | No | `default-value` |

## Outputs

| Output | Description |
|--------|-------------|
| `output1` | Example output value |
